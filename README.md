# Le monde de Amadou

## Description : 
Le site possède une page d'accueil qui contient une présentation personnelle, suivie d'une présentation professionnelle (parcours scolaire), et enfin une section "projets informatiques" dans laquelle je vais insérer tous les projets réalisés durant ces dernières années.  
Il y aura aussi deux autres pages accessibles en cliquant sur les éléments appropriés de la barre de navigation. Grâce au routage, elles permettront d'afficher dynamiquement :  
- une page de **création de projet**, dans laquelle on pourra remplir un formulaire pour créer dynamiquement un projet  
- une page **Pokémon API**, qui affichera le type du Pokémon ainsi que d'autres informations.

Voici quelques précisions sur la structure de mon site.  
Tout d'abord, mon site web possède une barre de navigation créée majoritairement à l’aide de **Bootstrap 5 React** :  
[https://react-bootstrap.netlify.app/docs/components/navbar/](https://react-bootstrap.netlify.app/docs/components/navbar/)
